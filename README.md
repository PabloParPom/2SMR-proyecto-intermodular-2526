# Proyecto Intermodular de 2º SMR
**Curso 2025|26**

En este repositorio se encuentra centralizada toda la información relativa al **Proyecto Intermodular de Sistemas Microinformáticos y Redes del CPIFP Alan Turing**, en la convocatoria del curso 2025|26.

## Requisitos y criterios a seguir

 1. Formato del proyecto
    - Trabajo en grupo (máx. 5 personas)
    - Debe partir de un anteproyecto aprobado previamente
    - Debe incluir Resultados de Aprendizaje (RAs) de distintos módulos (1º y 2º)
    - Debe responder a una necesidad real o simulada del sector

 2. Contenido
    - Memoria del proyecto, según guía facilitada
    - Presentación
    - Vídeo explicativo
    - Readme con un breve resumen del proyecto
 
 3. Criterios
    - Estudio del sector y detección de necesidades
    - Justificación del problema
    - Objetivos y alcance
    - Solución propuesta
    - Estudio de viabilidad técnica
    - Tareas y cronograma
    - Recursos (humanos y materiales)
    - Presupuesto
    - Reparto claro de tareas
    - Uso de herramientas TIC
    - Uso de lenguaje técnico adecuado
    - Uso de inglés en la presentación
    - Funcionalidad de la herramienta/proceso
